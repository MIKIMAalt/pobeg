НОЧНОЙ ПОБЕГ: сборка APK через GitHub (бесплатно)

1. Зайди на github.com и создай аккаунт (если нет).
2. Нажми "+" вверху справа -> "New repository". Назови, например, pobeg. Нажми "Create repository".
3. На странице нового репозитория нажми "uploading an existing file".
4. Распакуй этот архив на компьютере и перетащи в окно браузера ВСЁ его содержимое:
   папки .github, app, icons и этот файл. (Папка .github может быть скрыта:
   на Mac нажми Cmd+Shift+. чтобы показать скрытые папки.)
5. Внизу нажми "Commit changes".
6. Открой вкладку "Actions". Сборка стартует сама, занимает 3-6 минут.
   Если не стартовала: выбери "Собрать APK" слева -> "Run workflow".
7. Когда появится зелёная галочка, открой завершённую сборку, внизу в разделе
   "Artifacts" скачай nochnoj-pobeg-apk. Внутри zip лежит app-debug.apk.
8. Перенеси APK на телефон и открой. Разреши установку из неизвестных источников,
   если Android спросит.

Если сборка упала красным крестиком, открой её, скопируй текст ошибки и пришли мне.
